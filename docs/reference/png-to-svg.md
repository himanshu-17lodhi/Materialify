# PNG to SVG

## Overview

Materialify exclusively uses SVG (Scalable Vector Graphics) for icons. SVGs are lightweight, scale perfectly without pixelation, and support dynamic coloring.

## Configuration

### Converting Images

If you have a PNG or JPG icon you want to use, you must first convert it to SVG.

1. Use a tool like [Adobe Express PNG to SVG](https://www.adobe.com/express/feature/image/convert/png-to-svg) or [Vector Magic](https://vectormagic.com/).
2. Clean up the resulting SVG to ensure it only contains path data if you want it to support Materialify's color customization.

## Notes

- PNGs cannot be color-coded dynamically by Materialify.
- Large SVG files (complex vectors) may impact performance if used excessively.
