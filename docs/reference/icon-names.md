# Icon Names

## Overview

Every icon in Materialify has a unique identifier composed of a prefix (indicating the icon pack) and the icon's name.

## Configuration

### Identifying an Icon

To see the name of an icon currently assigned to a file:

1. Hover your mouse over the icon in the File Explorer.
2. A tooltip will appear with the full identifier (e.g., `LucideCalendar`).

![See icon name of file or folder](/public/screenshots/icon-of-file.png)

## Examples

| Pack             | Prefix   | Example Identifier |
| :--------------- | :------- | :----------------- |
| **Lucide**       | `Lucide` | `LucideCheck`      |
| **Font Awesome** | `Fa`     | `FaGithub`         |
| **Remix Icons**  | `Ri`     | `RiUserLine`       |

## Notes

- Prefixes are case-sensitive.
- Use these identifiers in [Frontmatter](/features/automation/frontmatter) or the [API](/developer/api).
