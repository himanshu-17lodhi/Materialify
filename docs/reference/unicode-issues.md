# Unicode Issues

## Overview

In some cases, you may see strange characters or "mojibake" in your notes where emojis or icons should be. This is usually related to font or encoding settings.

## Troubleshooting

### Enable Emoji Support

Ensure that Emojis are enabled in Materialify settings. Turning them off may cause the underlying Unicode characters to be rendered incorrectly by some themes.

1. Go to **Materialify Settings**.
2. Navigate to **Icon Packs**.
3. Ensure **Emoji Support** is enabled.

## Notes

- If issues persist, check if your system font supports the specific Unicode range for the icons/emojis you are using.
