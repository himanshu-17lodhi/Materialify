# File & Folder Icons

## Overview

The primary feature of Materialify is the ability to assign custom icons to any file or folder in your Obsidian vault. This allows for instant visual recognition and a more organized workspace.

## Use Cases

- **Project Management:** Assign unique icons to active project folders.
- **Visual Cues:** Use a "Warning" icon for notes that need review.
- **Aesthetics:** Create a beautiful, themed vault using consistent icon sets.

## Configuration

### Changing an Icon

1. **Right-click** any item in the File Explorer.
2. Select **Change Icon** (Shortcut: `Ctrl/Cmd + Shift + J`).
3. Browse or search for an icon.
4. Click the icon to apply it instantly.

### Priority System

Icons set directly on a file or folder have the **highest priority**. They will override icons set by:

1. Inheritance (Folders)
2. Custom Rules
3. Frontmatter

- **Work Folder:** `Briefcase`
- **Personal Vault:** `Heart`

## Notes

- Manual icons are stored in the plugin's `data.json` and persist across devices if using [Sync](/customization/syncing/overview).
- You can reset an icon by right-clicking and selecting **Remove Icon**.
