# Icon in Tabs

## Overview

Materialify can display icons directly in your Obsidian tabs, helping you identify open notes at a glance without reading the filenames.

## Use Cases

- Identifying multiple open notes with similar names.
- Keeping a consistent visual language between the File Explorer and the Tab bar.

## Configuration

### Enabling Tab Icons

1. Open **Materialify Settings**.
2. Navigate to **Appearance**.
3. Toggle **Show icons in tabs**.

![Icon in tabs settings option](/public/screenshots/icon-in-tabs-settings-option.png)

## Examples

Once enabled, any icon assigned to a file will automatically appear in its tab when opened.

## Notes

- If a file doesn't have a specific icon, the tab will show the default icon (if configured via Custom Rules).
- Tab icons may be hidden if the tab bar becomes too crowded.
