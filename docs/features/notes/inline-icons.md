# Inline Icons

## Overview

Materialify allows you to insert icons directly into your note content using a simple colon-syntax, similar to Slack or Discord.

## Use Cases

- **Task Lists:** Use icons to mark status (e.g., `:check:`, `:warn:`).
- **Documentation:** Add visual aids to your guides and notes.
- **Workflow:** Insert icons quickly without leaving the keyboard.

## Configuration

### Using Colon Syntax

In any note, type `:` followed by the name of an icon or emoji. A suggestion list will appear.

1. Type `:`.
2. Start typing the icon name (e.g., `:heart`).
3. Use arrow keys to select and press `Enter` to insert.

### Disabling Inline Icons

If you prefer to only use icons in the file explorer, you can disable the suggestion list.

1. Go to **Materialify Settings**.
2. Toggle **Icons in Notes**.
