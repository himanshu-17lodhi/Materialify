# Icon Packs Overview

## Overview

Icon Packs are the lifeblood of Materialify. They provide the actual SVG data used to render icons in your vault. Materialify supports a wide range of predefined open-source packs and allows you to create your own.

## Use Cases

- **Stylistic Consistency:** Choose a pack that matches your Obsidian theme.
- **Specialized Icons:** Use specific packs for RPGs, brands, or technical work.
- **Customization:** Import your own SVG assets as a personal icon pack.

## Configuration

### Accessing Icon Packs

All icon pack management is done within the **Materialify Settings**.

1. Navigate to **Materialify Settings**.
2. Look for the **Icon Packs** section.
3. Use **Browse icon packs** for predefined sets or **Add icon pack** for custom ones.

## Examples

- **Lucide:** Modern, clean, and consistent.
- **Font Awesome:** The industry standard for web icons.
- **Remix Icons:** Comprehensive and elegant.
