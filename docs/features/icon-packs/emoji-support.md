# Emoji Support

## Overview

In addition to SVG icon packs, Materialify fully supports native emojis. You can use emojis anywhere you use icons: file explorer, tabs, and notes.

## Use Cases

- Using familiar icons without downloading packs.
- Adding expressive visuals to note titles.

## Configuration

### Using Emojis

Emojis are available by default in the **Icon Picker** (`Ctrl/Cmd + Shift + J`). You can search for them by name (e.g., `:smile:`) or browse the emoji category.

### Styling Emojis

You can choose how emojis are rendered in the settings:

1. Go to **Materialify Settings** > **Appearance**.
2. Find **Emoji Style**.
3. Choose between:
   - **Native:** Use the operating system's default emoji style.
   - **Twemoji:** Use the consistent Twitter Emoji style.

## Examples

- `Native` emojis will look like Apple emojis on macOS and Windows emojis on PC.
- `Twemoji` will look the same across all devices.

- Some older operating systems may have limited support for newer Unicode emojis. In these cases, Twemoji is recommended for consistency.
