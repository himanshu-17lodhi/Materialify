# Icon Colors

## Overview

Materialify allows you to change the color of individual icons to make them stand out or to create a color-coded organization system.

## Use Cases

- **Urgency:** Set a "Red" icon for high-priority tasks.
- **Categorization:** Use "Green" for finished projects and "Blue" for active ones.
- **Aesthetics:** Match your icons to your theme's accent color.

## Configuration

### Changing an Icon's Color

1. **Right-click** on a file or folder that already has an icon.
2. Select **Change color of icon**.
3. Choose a color from the palette or enter a hex code.
4. Click **Apply**.

### Resetting to Default

To return an icon to the default editor color:

1. Open the color picker as described above.
2. Click the **Reset** button.

## Examples

- `Error.md` -> Red Icon
- `Success.md` -> Green Icon
