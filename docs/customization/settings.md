# Settings Overview

## Overview

Materialify offers a wide range of configuration options to tailor the plugin to your specific needs. Settings are divided into several logical sections for ease of use.

## Use Cases

- Accessing all plugin features from a single interface.
- Configuring automation and appearance defaults.
- Managing data and synchronization.

## Configuration

### Main Sections

1. **Appearance:** Controls how icons look in tabs, titles, and the file explorer.
2. **Icon Packs:** Management interface for downloading and updating icon sets.
3. **Automation:** Configuration for Custom Rules and Frontmatter support.
4. **Data & Syncing:** Options for managing your `data.json` and Obsidian Sync compatibility.

## Examples

> [!TIP]
> Most settings take effect immediately. If icons don't update, try reloading Obsidian.
