# Background Checker

## Overview

The Background Checker is a powerful utility that keeps your local icon packs in sync with your vault's configuration without manual intervention.

## Use Cases

- **Missing Icons:** Automatically download icons that were added on another device.
- **Housekeeping:** Remove unused icon files from your local storage to save space.
- **Performance:** Ensure you only have the files you actually need.

## Configuration

### Enabling the Background Checker

1. Go to **Materialify Settings**.
2. Navigate to **Data & Syncing**.
3. Toggle **Enable Background Checker**.

## Examples

If you add a "LucideHeart" icon on your Mac, your phone's Background Checker will notice the missing file and download it automatically the next time you open the app.

## Notes

- The checker runs periodically in the background to minimize CPU impact.
- It requires an active internet connection to download missing icons.
