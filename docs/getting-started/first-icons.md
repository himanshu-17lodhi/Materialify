# First Icons

## Overview

Learn how to manage your first set of icons and customize their appearance to match your workflow.

## Use Cases

- Assigning specific icons to key directories.
- Removing or resetting icons.

## Configuration

### Adding Icons

As covered in the [Quick Start](/getting-started/quick-start), the primary way to add icons is via the context menu.

### Removing Icons

To remove an icon from a file or folder:

1. **Right-click** the item.
2. Select **Remove Icon**.

## Examples

| Item Type    | Suggested Icon             |
| :----------- | :------------------------- |
| **Inbox**    | `Mail` or `Inbox`          |
| **Archive**  | `Archive` or `Folder-down` |
| **Settings** | `Settings` or `Gear`       |
