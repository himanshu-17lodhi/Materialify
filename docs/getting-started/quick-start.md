# Quick Start

## Overview

Get up and running with Materialify in minutes. This guide covers the essential steps to start iconizing your vault.

## Use Cases

- Setting up your first icon pack.
- Learning the basic "Change Icon" workflow.
- Exploring the built-in icon browsing interface.

## Configuration

### 1. Browse Icon Packs

Before you can add icons, you need to download an icon pack.

1. Go to **Materialify Settings**.
2. Click on **Browse icon packs**.
3. Select an icon pack (e.g., Lucide, Font Awesome, or Remix Icons).
4. Click **Download**.

### 2. Set Your First Icon

Once a pack is installed, you can add icons to your files and folders.

1. **Right-click** any file or folder in the File Explorer.
2. Select **Change Icon** (Shortcut: `Ctrl/Cmd + Shift + J`).
3. Search for an icon and click to apply.

## Examples

- **Folders:** Add a "Project" icon to your active projects.
- **Notes:** Use a "Checklist" icon for your tasks folder.

## Notes

- Icons set manually on files or folders have the highest priority and will override any custom rules.
- You can change the icon color in the individual icon settings.
