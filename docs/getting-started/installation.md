# Installation

## Overview

Materialify is designed to be easily installed and configured. This guide covers the various ways you can add the plugin to your Obsidian vault.

## Use Cases

- New users looking to enhance their vault's visual organization.
- Users migrating from other icon plugins.
- Developers testing the latest features via manual installation.

## Configuration

### Community Plugins (Recommended)

The easiest way to install Materialify is through the Obsidian Community Plugins store.

1. Open **Obsidian Settings**.
2. Navigate to **Community Plugins**.
3. Click **Browse** and search for `Materialify`.
4. Click **Install**, then **Enable**.

### Manual Installation

If you want to use a specific version or a pre-release, you can install it manually.

1. Download the latest release from the [GitHub releases](https://github.com/himanshu-17lodhi/Materialify/releases/).
2. Extract the `zip` file into your vault's plugin folder: `<vault>/.obsidian/plugins/materialify/`.
3. Reload Obsidian or go to **Community Plugins** and enable **Materialify**.
